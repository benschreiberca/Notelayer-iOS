What is Electron?

Electron packages a webpage + Node.js into a desktop app (.exe on Windows, .app on Mac, Linux binary). It's how VS Code, Slack, Figma, Discord, Notion and 1Password are built.

The key idea: you write your app once in HTML/CSS/JavaScript (or React), and Electron wraps it in a Chromium browser window that looks and behaves like a native desktop app — with access to the filesystem, notifications, menus, etc.

// Your React webapp is already Electron-ready. // You'd just add one config file and a launcher: electron-app/ main.js ← opens a window that loads your React app package.json ← "start": "electron ." // That's it. No rewrite needed.

✅ Electron pros

  • Zero rewrite — your React webapp IS the app
  • One codebase: web + Chrome ext + desktop
  • Full Node.js access (filesystem, notifications, tray icon)
  • Ships on Mac, Windows, Linux from one codebase
  • Huge ecosystem, well-documented

⚠️ Electron cons

  • Large app size (~150–200MB) — ships its own copy of Chrome
  • High RAM usage (50–150MB baseline)
  • Not in the Mac App Store easily
  • Updates require re-downloading the whole app
  • Doesn't feel "native" to power users

Tauri — the recommended desktop path

🦀 What makes Tauri different

  • Uses the operating system's own browser engine (WebKit on Mac, WebView2 on Windows) — so no bundled Chrome
  • Result: 3–8MB app vs 150MB for Electron
  • The Rust backend is tiny and fast
  • Your React frontend is unchanged
  • Better memory usage — Safari/Edge instead of a second Chrome

📲 PWA — the zero-effort option

  • Add a 20-line manifest.json to the React app
  • Chrome shows "Install Notelayer" in the address bar
  • Opens in its own window, no browser chrome
  • Works on Android, Mac, Windows, ChromeOS
  • No app stores, no build step, no distribution
  • Limitation: no deep OS integration (tray icon, file access)

Glossary

Firestore — Google's real-time database. Already in your iOS app. The web SDK is identical in JavaScript — same data, same real-time sync, different language.

Electron — A framework that bundles a copy of Chrome + Node.js + your webapp into a distributable desktop application. Used by VS Code, Slack, Figma, Discord, Notion.

Tauri — Like Electron but ~20× smaller. Uses the OS's built-in browser instead of bundling Chrome. Your React app works unchanged. Built with Rust for performance.

PWA (Progressive Web App) — A webpage with a manifest.json that tells Chrome/Safari "this can be installed as an app." Free Android and desktop app from your webapp with almost zero extra work.

React Native — React for mobile — components compile to native iOS/Android UI. You share logic but rebuild the UI in React Native primitives. Different from React (web).

Capacitor — Ionic's tool that wraps your existing React webapp in a native iOS/Android shell. Think of it as Electron for mobile. Gives access to native device APIs.

Flutter — Google's cross-platform framework using Dart (a different language). Renders its own UI widgets — not web tech. Full rewrite required, but genuinely native performance on all platforms.

Chrome Side Panel — A persistent panel that opens on the side of Chrome (like the reading list). The Chrome extension API lets you load any URL there. We load our webapp URL.
